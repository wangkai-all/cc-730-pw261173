# 工艺关系分析站（虚构教学数据）

一个零依赖、可离线打开的静态站点，用虚构批次的**温度、速度 → 损耗**数据演示：
普通最小二乘（OLS）与稳健（Huber）回归的差异，以及**结论是否会被少数来源批次带偏**。

## 运行

无需构建、无需联网、无第三方库。任选其一：

```bash
# 方式一：直接用浏览器打开
open index.html          # macOS
xdg-open index.html      # Linux

# 方式二：本地静态服务器（文件导入/fetch 体验更完整）
python3 -m http.server 8099
# 浏览器访问 http://localhost:8099
```

## 测试（Node 内置，无依赖）

```bash
node tools/verify-behavior.js     # 四个教学批次的数值行为断言
node tools/test-integration.js    # 流水线 / LBO / 降秩 / 预测 / 导入去重
node tools/test-ui-stub.js        # 最小 DOM 桩驱动完整 UI 交互流程
```

## 数据设计（确定性生成，种子 20261123）

14 个批次 × 8 条测量 = 112 条，跨 3 个来源（S1/S2/S3）、3 个工况（C1/C2/C3）。
四个批次承担明确的教学角色，其行为由 `tools/verify-behavior.js` 的断言守护：

| 批次 | 角色 | 预期现象 |
|---|---|---|
| **B-HL** | 高杠杆、小残差 | 学生化残差不报警，但删除后温度系数大幅变化（Δ≈-1.01 标准化单位）；Huber 对它几乎不降权 |
| **B-RANK** | 唯一覆盖工况 C3 | 删除后设计矩阵列共线、数值秩 4/5，页面拒绝报系数 |
| **B-OUT** | 单条测量异常 | 一条 \|学生化残差\|>4，但杠杆普通，整批删除对系数影响很小 |
| **B-SHIFT** | 整批恒定偏移 | 单条都不越异常线，但批次平均残差大、内部一致，Huber 整体降权 |

重新生成数据：`node tools/generate-sample.js`（同时产出内嵌 `js/sample-data.js` 与 `sample-data/*.csv`）。

## 方法口径（页面页脚同述）

- **设计矩阵**：截距 + z(温度) + z(速度) + 工况哑变量 C2、C3（C1 为基准）。
- **标准化**：均值与总体标准差**只由参与拟合的训练批次**估计；排除批次后整套参数重新估计。
- **OLS**：带列主元的 Householder QR，数值秩容差 1e-10。秩不足时系数置空、不输出虚高数字。
- **稳健方案**：Huber IRLS，调节常数固定 k=1.345（非数据驱动），MAD 尺度；尺度与权重只在训练批次上估计。
- **整批删除（LBO）**：选择排除批次后，**真实地**重新标准化并重新求解 QR/IRLS，
  不是 Cook's D / DFFITS / DFBETA 那类单点一阶近似。测试中二者数值显著不同（见下）。
- **分组验证**：5 折按整批划分，验证折整批不参与任何参数；OLS 与 Huber 用同一随机种子、相同折分配。
- **预测范围**：温度/速度落在训练覆盖矩形内且工况有样本才标“覆盖内”，否则明确标“外推”并给出原因；降秩情景不输出预测。

## 关键工程约束（对应需求）

- 导入记录保留来源、批次、测量编号；`measurement_id` 全局去重，重复测量文件 0 新增、不重复计权。
- 单条异常与整批偏移是两套独立诊断（残差阈值 vs 批次均值+内部一致性）。
- 排除操作只创建**分析情景**：原始存储行数与行对象永不改变，可疑批次不会被自动当错误删除。
- 降秩 / 工况无覆盖时，页面说明“结论无法继续比较”，不报巨大系数、不填占位误差。
- 颜色按来源实体固定，不随筛选重排；每个图表都有等价的表格视图（无障碍/打印）。

## 目录

```

js/
  rng.js              确定性伪随机
  stats.js            QR/OLS、Huber IRLS、诊断量、分组 CV（纯数学）
  pipeline.js         设计矩阵、标准化、LBO 真实重拟合、预测与覆盖判定
  importer.js         CSV 解析、measurement_id 去重、导入台账
  sample-data.js      生成器产出的内嵌数据
  charts.js           零依赖 SVG 图表（悬浮提示、键盘 focus、表格数据）
  app.js              状态与视图编排
sample-data/*.csv     与内嵌数据一致的真实 CSV，供文件导入
tools/                生成器与三套测试
```
